### 正文字体大小

**配置项名称：`articles.style.font_size`**

| 类型 | 备注 | 可选值 | 默认值 |
| :---: | :---: | :---: | :---: |
| 字符串 | 如无特别需要不建议更改 | "*px" | `"16px"` |

### 正文行高

**配置项名称：`articles.style.line_height`**

| 类型 | 备注 | 可选值 | 默认值 |
| :---: | :---: | :---: | :---: |
| 数字 | 如无特别需要不建议更改 | 1-5 | `1.5` |

### 标题间距

**配置项名称：`articles.style.heading_spacing`**

控制 Markdown 标题的顶部间距，同时保持 `h1` 到 `h6` 逐级递减的间距层次。

| 类型 | 可选值 | 默认值 |
| :---: | :---: | :---: |
| 字符串 | `compact \| default \| spacious` | `default` |

已有站点仍可使用旧的
`articles.style.headings_top_spacing.h1` 到 `.h6` 配置。旧配置会覆盖对应标题级别的预设值，未配置的级别则使用所选预设。

## 文章版权

### 开关

**配置项名称：`articles.copyright.enable`**

是否在文章末尾展示文章版权信息。

| 类型 | 可选值 | 默认值 |
| :---: | :---: | :---: |
| 布尔值 | `true \| false` | `true` |

![](https://assets.ohevan.com/img/9c510e3a30ee607646831dd613732434.png)

### 默认版权信息

**配置项名称：`articles.copyright.default`**

可选值：

- `all_rights_reserved`：保留所有权利。
- `cc_by_nc_sa`：署名-非商业性使用-相同方式共享，详情请见 [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/deed.zh)。
- `cc_by_nc`：署名-非商业性使用，详情请见 [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/deed.zh)。
- `cc_by_nd`：署名-禁止演绎，详情请见 [CC BY-ND 4.0](https://creativecommons.org/licenses/by-nd/4.0/deed.zh)。
- `cc_by_sa`：署名-相同方式共享，详情请见 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/deed.zh)。
- `cc_by`：署名，详情请见 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/deed.zh)。
- `public_domain`：公有领域，详情请见 [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/deed.zh)。

<Callout type={"info"} >
    **自定义版权信息**

    如需自定义文章使用的版权信息，请在文章的 Front-matter 中添加 `license` 字段，比如：

    ```yaml
    ---
    title: Hello World
    date: 2021-03-22 19:20:00
    license: all_rights_reserved
    ---
    ```

    可选值请参考上面的说明。

    请注意，如果你的文章 Front-matter 中有 `license` 字段，那么这个字段的值会覆盖 `default` 的值。

    如果以上选项不能满足你的需求，你可以在主题配置文件中使用 `copyright` 自定义说明信息，比如：

    ```yaml
    ---
    title: Hello World
    date: 2021-03-22 19:20:00
    copyright: 本文是瞎写的，你如果要用的话，后果自负。
    ---
    ```
</Callout>

<Callout type={"warning"} emoji={"⚠️"}>
    请注意，`copyright` 项比 `license` 优先级更高。所以如果你两个都写了，只有 `copyright` 会生效
</Callout>

## 文章推荐

自动根据文章关键词，推荐相关文章。

需要安装 `nodejieba` 模块。迁移自 `hexo-theme-volantis`。

请执行以下命令安装：

```bash
npm install nodejieba@latest
```

### 开关

**配置项名称：`articles.recommendation.enable`**

是否开启推荐文章。

| 类型 | 可选值 | 默认值 |
| :---: | :---: | :---: |
| 布尔值 | `true \| false` | `false` |

### 标题

**配置项名称：`articles.recommendation.title`**

推荐文章这个区块的标题。

| 类型 | 备注 | 默认值 |
| :---: | :---: | :---: |
| 字符串 | 无 | `推荐文章` |


### 推荐数量

**配置项名称：`articles.recommendation.limit` 和 `articles.recommendation.mobile_limit`**

`limit` 指的是在电脑端推荐文章的数量，`mobile_limit` 指的是在手机端的推荐文章数量。

| 类型 | 可选值 | 默认值 |
| :---: | :---: | :---: |
| 数字 | `1-10` | `3` |

### 排除目录

**配置项名称：`articles.recommendation.skip_dirs`**

推荐文章时，排除的目录。

| 类型 | 备注 | 示例 |
| :---: | :---: | :---: |
| 数组 | 请用英文逗号分隔 | `["/docs/", "/private/"]` |
